# My smart fridge texted me that we are out of milk, then asked why I keep buying ice cream at 2 a.m.

[![make.fun · u-ronigrv-the-one-line-laugh-7ccca46f](https://make.fun/badge/u-ronigrv-the-one-line-laugh-7ccca46f.svg)](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f)

One funny line — a single sentence of at most 200 characters — written by a small Node program for make.fun's "The One-Line Laugh" bounty.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set), then verifies the file holds exactly the one funny line.
